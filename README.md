![React](https://img.shields.io/badge/React-v18-blue)

![License](https://img.shields.io/badge/License-MIT-green)

**LinguaFlow** is a modern, real-time voice and text translation application. It helps users communicate across languages instantly using AI speech recognition.

🔗 **[Click Here to See Live Demo](https://linguaflow-app.vercel.app)**

---

## ✨ Key Features

- **🎙️ Listens:** You can speak into the microphone, and it captures your voice.
- **⚡ Translates:** It instantly converts your speech into other languages (Tamil, French, Spanish, etc.).
- **🎨 Looks Modern:** Features a "Glassmorphism" design (transparent, glowing UI) built with Tailwind CSS.
- **📱 Works Everywhere:** Fully responsive on phones, tablets, and laptops.
- **💾 Vault:** Lets you manually save your favorite translations to a local history list.

---

## 🛠️ The Tech Stack

- **Frontend:** React.js (The core framework)
- **Styling:** Tailwind CSS (For the modern look - *Refactored in v2.0*)
- **Speech Engine:** Web Speech API (For voice recognition)
- **Deployment:** Vercel (For hosting the website)

## 🚀 How to Run Locally

If you want to run this code on your own laptop:

1. **Clone the repo:** `git clone https://github.com/janavkamesh/lingua-world.git`
2. **Install tools:** `npm install`
3. **Start app:** `npm run dev`
